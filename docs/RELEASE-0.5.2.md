# Video Sheet to PDF 0.5.2

The video area now shows **Loading video…** with a spinner as soon as loading
starts, instead of the empty **Load a video** prompt. It remains visible through
download, preparation, and first-frame decoding, including replacement videos
and browser file uploads. Failed or cancelled loads clear the loading screen.

The message supports English, Korean, and Japanese. Reduced-motion preferences
disable the spinner animation.

Verified loading and first-frame readiness, translated phone layouts, replacement
failure, cancellation, rejected requests, and failed browser uploads.

Download the portable Windows x64 EXE and double-click it. Existing projects remain
compatible. Python, FFmpeg, and Node.js are bundled. The EXE is unsigned.
