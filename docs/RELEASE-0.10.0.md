# Video Sheet to PDF 0.10.0

Adds **Free** capture mode for outlined blue chords and white lyrics over video.
Draw a rectangle around the text, set the start/end times, and select
**Extract text lines**. The detector handles changing row counts, including
chord-only passages, and preserves the original colors and source frames.

Free has its own capture list and supports crop editing, undo, saved projects,
and PDF export. Review results for occasional duplicates or annotations inside
the selected rectangle.

Run `Video-Sheet-to-PDF-0.10.0-win-x64.exe`. Python, FFmpeg, and Node.js are
included; no separate installation is needed.
