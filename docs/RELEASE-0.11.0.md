# Video Sheet to PDF 0.11.0

- Adds **Chord**, **코드/가사**, and **コード/歌詞** mode for automatic capture
  of outlined blue chords and white lyrics inside a selected rectangle,
  including chord-only passages. Existing Free-mode projects remain compatible.
- Makes **Extraction settings** a visible button with a right-aligned chevron.
- Adds **Background cleanup** in Review & export: **White** (default), **Black**,
  or **Off — original capture**. The choice applies to line previews, print
  previews, and PDF output, and is saved with the project. Stored captures and
  source images remain available for crop editing.
- Fixes TAB arrangement when a manually selected crop has a small margin after
  its final barline. Two-bar captures can now combine into four-bar print rows.
- Removes the requested reference-video paragraph from the README.

Run the portable Windows x64 EXE. Python, FFmpeg, and Node.js are included.
