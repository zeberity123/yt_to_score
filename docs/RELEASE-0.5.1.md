# Video Sheet to PDF 0.5.1

The Exclude line, Undo, Move up, and Move down buttons now size to their labels,
with more padding and a 44-pixel minimum height. On phones they use two columns
so translated labels stay inside their buttons.

Verified English, Korean, and Japanese at widths from 320 to 1440 pixels, with
space on both sides of every label and no horizontal page overflow.

Download the portable Windows x64 EXE and double-click it. Existing projects
remain compatible. Python, FFmpeg, and Node.js are bundled. The EXE is unsigned.
